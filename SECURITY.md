# Security Policy

## Supported Versions

This project is actively maintained on the default branch.

## Reporting a Vulnerability

If you discover a security issue, please do not open a public issue.

Please report it privately through GitHub Security Advisories for this repository.

Include:

- A clear description of the issue
- Steps to reproduce
- Potential impact
- Any suggested remediation

I will acknowledge receipt as quickly as possible and follow up with status and remediation timing.
